# Kuaför Tanıtım Sayfası (Örnek)

Küçük bir kuaför için hazırlanmış tek sayfalık tanıtım sitesi örneği. Fiyat listesi, çalışma saatleri ve WhatsApp ile randevu düğmesi içerir. Telefonda ve bilgisayarda düzgün görünür, koyu temayı destekler.

**Canlı sayfa:** https://mehmetcan-cell.github.io/kuafor/

Teknolojiler: HTML, CSS

# Hair Salon Landing Page (Sample)

A one-page website sample for a small hair salon. It includes a price list, opening hours, and a WhatsApp booking button. It works well on phones and desktops and supports dark mode.

**Live page:** https://mehmetcan-cell.github.io/kuafor/

Built with: HTML, CSS
